# Repository collaboration rules

- After completing and verifying a requested repository change, commit the task-scoped files and push the current branch to `origin` automatically.
- Keep `origin` pointed at `https://github.com/JonathanOwenTJ/wx_channels_download.git`; use `upstream` only to fetch changes from the original project.
- Never commit credentials, cookies, tokens, local download content, runtime logs, generated executables, or machine-specific configuration.
- Preserve unrelated working-tree changes and include only files that belong to the completed request.
- Before pushing, run the relevant tests and confirm that the pushed remote commit matches the local branch.
